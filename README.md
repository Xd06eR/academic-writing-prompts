Prompt templates for producing high-quality academic essay sections through structured outlining, iterative drafting, and self-critique.

## Version Guidance

Use the latest version available in each language folder, as newer versions typically include refinements and clearer instructions.

## Quick Usage

1. Open a prompt and paste it into your LLM chat.
2. Fill in all placeholder fields (topic, audience, citation style, section scope, word counts).
3. Generate the outline first, then draft and iterate until the target score is reached.
4. Manually verify claims, citations, and formatting before submission.
