# Example — AI Coding Assistants and Junior-Developer Debugging Skill

> **⚠️ Synthetic worked example, not a real student run.**
>
> Every file in this folder was generated by an LLM as a demonstration of what each phase of the pipeline produces. No human student wrote this essay, ran the grill loop, or verified the citations. The pipeline was executed by the LLM playing both roles (Socratic editor and student) to produce a faithful, end-to-end illustration of the workflow.
>
> Treat this as a **shape reference**, not a finished artefact:
> - The grill-loop transcript in `1-capture-output.md` shows the *format* of a real loop. A real student's answers would be terser, messier, and would push back more.
> - The Source map in `2-lit-review.md` contains two sources marked `[VERIFY]` exactly because the LLM could not confirm them. In a real run the student would either verify each URL or replace the row.
> - The draft and refine outputs in `4-draft-output.md` and `5-refine-output.md` are LLM-written prose. They are competent academic English but they have not been read by a human professor and have not gone through real disciplinary scrutiny.
>
> Future revisions of this repo will replace this synthetic run with a real student's output when one is available.

## Topic

Generative AI coding assistants harm junior developers' acquisition of debugging skill by displacing the productive struggle that builds the mental models debugging depends on.

- **Discipline:** Human–Computer Interaction with a cognitive-psych frame
- **Citation style:** APA 7
- **Length:** 2000 words, full essay
- **Stance choice:** Argue from inside the experience, not as moral panic; engage the productivity counterargument (Peng et al. 2023) honestly rather than dismissing it.

## How to use this example

- Reading order: 0 → 1 → 2 → 3 → 4 → 5.
- Look at `1-capture-output.md` first if you want to see the grill loop in action — it is the most distinctive part of the pipeline.
- Look at `2-lit-review-output.md` if you want to see how the skill handles uncertain citations (the `[VERIFY]` rows are deliberate).
- Use the prompts in `skills/academic-writing/steps/` (or invoke the orchestrator skill directly) to run your own essay through the same pipeline.
